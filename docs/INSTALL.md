# 安装、升级与卸载

## 下载安装

从 [GitHub Releases](https://github.com/ZeroClian/stockbar/releases/latest) 下载 **Tickfin 1.2.1**。旧版 v1.1.0 的应用名为「自选股」，升级时请先退出旧应用。

| 文件 | 用途 |
| --- | --- |
| `Tickfin-<版本>-arm64.dmg` | 推荐；打开后将「Tickfin」拖入 Applications |
| `Tickfin-<版本>-arm64.zip` | 解压后手动移动应用 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |

仅发布 Apple Silicon（M 系列芯片）版本。部署目标 macOS 13+；最低版本与 Intel 未实机验证。不要将 arm64 安装包当作 Universal 包。

DMG 内的 Applications 是安装目标快捷方式。复制完成后弹出映像，从应用程序文件夹启动。菜单栏出现单色鱼形 K 线标记，无 Dock 图标；点标记打开面板，偏好页可退出。

## 首次打开被阻止

本版仅 ad-hoc 签名，未使用 Apple Developer ID，未公证。macOS 可能提示无法验证开发者。

确认下载自本项目 Release 并核对校验值后，尝试打开一次，再到「系统设置 → 隐私与安全性」找到对应应用提示，按系统提供的「仍要打开」流程操作。不同 macOS 的文字可能有差异。不要关闭 Gatekeeper，也不要运行来源不明的修复脚本。

如果系统明确报告恶意软件、下载损坏或校验不一致，停止安装并反馈，勿绕过。具体说明见 [Apple 官方支持](https://support.apple.com/102445)。

校验单个下载包（将文件名改成你下载的版本）：

```bash
shasum -a 256 Tickfin-1.2.1-arm64.dmg
```

与同一个 Release 中 `SHA256SUMS.txt` 的对应行比较。如果下载了所有包，可在同目录运行 `shasum -a 256 -c SHA256SUMS.txt`；只下载其中一个时，其他文件缺失属于预期。

## 全局快捷键

偏好 → 全局快捷键 → 点击设置，按下组合键并松开主按键保存；再次点击可改键，「清除」停用。建议使用 ⌃⌥空格；若被占用可换其他组合。至少两个修饰键，包含 ⌃ 或 ⌘，主按键为字母、数字、空格或左右方向键；不接受单键、仅修饰键或显式 Fn 组合。方向键自带的 Fn 标志不影响录制。

可分别设置“打开／收起”“上一只”“下一只”三组快捷键，不可重复。打开／收起使用同一组合键，收起恢复遮罩；上一只／下一只按自选顺序循环切换状态栏关注项，不展开面板。录制中 Esc 取消；按已有快捷键仅结束录制。默认不占用任何组合键。设置在本机保存，应用运行期间才生效，不需要辅助功能或输入监控授权。

系统快捷键及其他已注册全局组合会检测冲突；其他应用的菜单／内部快捷键无法穷尽检测，请避免常用组合。按物理键位记录，界面使用美式字母标识；切换非美式键盘布局时位置不变。若重启时被其他应用占用，偏好页显示不可用，需重新设置；原设置仍保留。

## 刷新与后台提醒

偏好 → 刷新，设置 5–300 秒整数并保存；此间隔也决定提醒采样频率。关闭面板不会停止后台监测，静默小点或系统通知仍按已保存规则生效。休眠和退出会停止监测。

休市（午休、周末和内置节假日）不请求行情，开市恢复；手动添加股票的代码验证仍会查询接口。休市重启显示上次缓存，若此前未生成缓存则等待开市。日历当前覆盖 2026 年，超出范围会显示“日历需更新”并暂停监测，需升级含新日历的应用。

主页图钉可切换关注股票；上下箭头可调整自选顺序。选择关注股票不会自动改变“仅图标”隐私模式。

## 升级

从 1.2.1 起：偏好 → 版本与更新 → 检查更新 → **立即更新**。应用自动下载适配芯片的正式版 ZIP，校验 SHA-256、应用标识、版本、签名和架构，退出旧进程后在原位置替换并重启。新版启动确认后删除下载 ZIP、解压目录、更新助手和旧应用；失败时保留或恢复旧版并清理本次临时文件；若回滚本身失败，会保留恢复所需备份。持仓与设置数据保留。只在用户点击后更新，不会在后台擅自安装。

更新准备期间普通退出会暂缓，待更新助手接管后自动重启；请勿强制结束进程。强制退出、断电或目录失去写权限时可能留下恢复文件，不保证完成自动清理。

请只保留一个安装副本，放在 `/Applications/Tickfin.app`（推荐）或 `~/Applications/Tickfin.app`，并确保该位置可写。不要从下载目录、DMG 或多个构建目录长期启动；复制安装后删除下载或解压的多余副本并弹出 DMG。偏好中的“显示当前应用位置”可核对正在运行的副本。应用内更新不会额外留下下载包。

旧版 1.2.0 仍需点击“下载新版”打开 GitHub Release 后手动替换；升级到支持一键更新的版本后即可使用新流程。发布包缺少校验信息或不适配芯片时仍提供手动下载入口。

1. 从应用偏好页退出，避免两份应用同时写同一数据文件。
2. 如需备份，复制 `~/Library/Application Support/StockBar/state.json` 到自己的安全位置。
3. 将 Tickfin.app 放入 Applications，选择替换原应用，再启动。由旧版「自选股.app」升级时，先退出并删除旧应用包；不要删除 Application Support 中的数据目录。

Tickfin 沿用原 bundle identifier 和 `~/Library/Application Support/StockBar` 数据目录，保留自选、持仓、提醒与快捷键设置；不用手动搬迁数据。

1.1.0 保留 1.0.x 自选、股数、成本、阈值与去重记录，默认改为图标状态栏、代号和静默提醒。系统通知可按股票重新主动选择。新版本数据不保证可被旧版本读取，降级前先保存并使用对应旧备份。

## 常见问题

- **找不到窗口**：这是菜单栏应用。看右上角鱼形 K 线标记，或再次打开应用。刘海屏菜单项过多时可能被系统隐藏。
- **为什么没有通知横幅**：默认是静默小点。主动改为系统通知后，还需检查系统通知权限与专注模式。
- **金额是圆点**：点眼睛显示。收起面板后自动恢复隐藏。
- **行情带「旧」**：报价过期、非当日或更新失败；旧行情不会触发提醒。休市时不会模拟新数据。
- **添加不了股票或 ETF**：可输入六位交易代码（如 `300750`、`510300`、`159915`）或拼音首字母（如 `NDSD`），最多显示 5 条候选，点击右侧“＋”添加。不支持指数、LOF、场外基金或中文全名搜索。搜索接口不可用时可尝试完整代码查询。
- **数据文件损坏**：应用停止写入和提醒以保护原文件；先退出并备份，再用自己确认有效的备份恢复，不要随意删除持仓文件。

## 卸载

从偏好页退出，删除 Applications 中的「Tickfin」。这不会删除持仓。若确认不再需要，先备份，再手动移除 `~/Library/Application Support/StockBar`；该操作不可恢复未备份数据。
