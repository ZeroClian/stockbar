- 30 个原生 SwiftUI 离屏渲染状态覆盖快捷键、排序页、刷新与更新组件及完整设置页。首页 280×186pt，排序页 280×178pt，设置页 280×365pt，录制 280×378pt，校验错误 280×397pt；长消息、恢复首页和短屏高度断言通过。

- 生产 release 构建、严格 ad-hoc 签名、DMG 完整性、ZIP 与 SHA-256 校验通过；此前功能代码独立复核未发现阻断缺陷。

## 复现

```bash
bash scripts/test.sh
bash scripts/build-app.sh
bash scripts/render-preview.sh
bash scripts/package-release.sh --skip-build
```

CI 在 macOS runner 上执行测试、构建和打包，不读取个人持仓、不发送系统通知、不把网络行情作为必须成功的测试依赖。实际状态见仓库 Actions；仅当对应提交运行成功才说明该版本 CI 通过。
