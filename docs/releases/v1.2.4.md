# Tickfin v1.2.4

Bark 正式通知现在直接显示价格或盈亏数值。

- 价格提醒：发送设置阈值和实际触发价格，保留股票 / ETF 价格精度。
- 盈亏提醒：按规则发送金额或百分比；涨跌幅和盈亏提醒另附当前价格。
- 移除数值开关，已有配置直接生效，无需重新保存密钥。标题仍跟随触发规则，补充说明可编辑，不发送行情时间。

**升级后，Bark 正式通知会包含对应价格或持仓盈亏，即使旧版关闭过数值选项。**

## 安装与升级

Apple Silicon / macOS 13+：下载 `Tickfin-1.2.4-arm64.dmg`，或在应用内检查更新。ZIP 用于应用内更新，`SHA256SUMS.txt` 用于完整性校验。保留原自选、持仓、提醒及快捷键设置。
