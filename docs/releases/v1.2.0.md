# Tickfin v1.2.0

应用更名为 **Tickfin**，采用鱼形与红绿 K 线图标，菜单栏保留单色简化标记。本版本让日常查看更快捷，并减少休市请求。

- 自定义全局打开／收起快捷键，默认未设置。
- 5–300 秒自定义刷新间隔，默认 15 秒；面板关闭后仍在交易时段监测提醒。
- 午休、周末和 2026 年节假日不刷新，开市恢复；休市可显示上次缓存。
- 自选上下排序、图钉菜单快速切换状态栏关注股票。
- 手动检查正式版本和打开下载页，不自动更新。
- 修复偏好设置展开后的水平偏移，保持固定宽度，较长内容可纵向滚动。

升级前退出旧应用，备份本机 state.json，再安装 Tickfin.app 并移走已退出的旧「自选股.app」。沿用原应用标识与 `~/Library/Application Support/StockBar` 数据目录，无需搬迁文件。自选、持仓、提醒规则、代号和快捷键会保留；旧数据默认使用 15 秒间隔。

注意：当前日历仅覆盖 2026 年，超出范围会显示“日历需更新”并暂停监测，需安装包含新日历的版本。提醒依赖运行中的应用、有效新行情和刷新采样；休眠、退出时不监测。

提供 `Tickfin-1.2.0-arm64.dmg`、`Tickfin-1.2.0-arm64.zip` 与 `SHA256SUMS.txt`。安装包使用 ad-hoc 签名，未使用 Apple Developer ID 签名或公证；macOS 13 与 Intel 未实机验证。下载安装与首次打开步骤见 [安装指南](https://github.com/ZeroClian/stockbar/blob/v1.2.0/docs/INSTALL.md)。

验证：71 项自动化测试、30 个原生 SwiftUI 离屏预览，以及签名、DMG、ZIP 和 SHA-256 校验。离屏检查与替身通知测试不代表真实交易时段长时间监测、系统横幅或跨应用物理快捷键实测；详细范围见 [验证记录](https://github.com/ZeroClian/stockbar/blob/v1.2.0/docs/VALIDATION.md)。
