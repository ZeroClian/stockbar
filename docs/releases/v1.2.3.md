# Tickfin v1.2.3

更顺手的键盘操作、更清楚的设置，以及更省心的 Bark 推送。

- **键盘操作**：↑↓ 选股、回车查看，⌘1 / ⌘2 自选与持仓、⌘3 提醒、⌘R 刷新、⌘S 保存。⌘K 查看完整清单，全局快捷键仍可自定义。
- **设置整理**：偏好按六类展示，快捷键统一保留在“显示与快捷键”；提醒通道单独设置，输入框支持复制粘贴。
- **手动刷新**：开市、休市都可主动获取行情；自动刷新休市暂停，面板关闭不影响交易时段提醒。
- **Bark 优化**：完整网址一键导入；打开设置不触发钥匙串授权；通知按规则生成标题、显示真实名称、移除行情时间；测试采用当前关注项。

## 安装与升级

Apple Silicon / macOS 13+：下载 `Tickfin-1.2.3-arm64.dmg` 安装，或在旧版应用中检查更新。ZIP 用于应用内更新，`SHA256SUMS.txt` 用于校验。保留自选、持仓、提醒和快捷键；仅保留固定安装位置的一个应用副本。

包采用 ad-hoc 签名，尚未 Apple 公证。Bark 若要求重新授权，请到连接页手动保存；默认正式通知不含价格或盈亏，但显示真实股票名称，测试消息会包含当前价格。

133 项自动化测试与原生布局检查通过；真实手表接收、跨应用物理快捷键和最低系统版本未完整验收。
