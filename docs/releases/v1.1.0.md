StockBar 首个公开版本：原生 macOS 菜单栏 A 股工具，提供涨跌、持仓盈亏与阈值提醒。

## 下载安装

- **推荐**：`StockBar-1.1.0-arm64.dmg`，打开后将「自选股」拖入 Applications。
- **备用**：`StockBar-1.1.0-arm64.zip`，解压后移动应用。
- **校验**：`SHA256SUMS.txt`，用 `shasum -a 256 文件名` 比较对应值。

支持 Apple Silicon；部署目标 macOS 13+，macOS 13 与 Intel 未实机验证。本版仅 ad-hoc 签名，**未 Developer ID 签名或公证**，首次打开可能被系统阻止。核对来源后按 [安装指南](https://github.com/ZeroClian/stockbar/blob/v1.1.0/docs/INSTALL.md)操作。

启动后在菜单栏找省略号，没有 Dock 图标，不会自动弹出面板。

## 本版内容

- 280pt 单色小面板，默认代号与持仓遮罩，主动点眼睛显示。
- 沪深北 A 股，修复创业板 300750 和科创板行情解析。
- 当前持仓录入、当日估算和浮动盈亏。
- 默认静默小点，按股票主动选择系统通知；重启去重、已读不重复提醒。
- 长文字折叠、提示详情、关闭后迟到异步结果失效。

## 升级与数据

先退出旧应用，再替换安装。保留旧自选、股数、成本、阈值与去重记录；旧默认显示调整为图标，提醒渠道调整为静默。数据位于 `~/Library/Application Support/StockBar/state.json`，建议升级前自行备份。无自动更新。

## 验证与限制

46 项本地测试通过，14 个原生离屏视图状态验证通过。真实接口已验证包含 300750 的六只证券，检查时为收盘数据。未完成真实系统横幅、完整桌面点击、最低系统和 Intel 实机验收。公开行情可能延迟；休眠或退出期间不监控，不接入券商或交易。
