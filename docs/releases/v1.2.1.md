# Tickfin v1.2.1

轻量查看 A 股与 ETF，新增搜索、价格 / 盈亏提醒和应用内一键更新。

## 新功能

- **沪深场内 ETF**：支持股票、跨境、商品、债券与货币 ETF，例如 `510300`、`159915`、`588000`。ETF 价格与每份涨跌额保留三位小数，持仓单位为“份”。
- **代码 / 拼音搜索**：输入 `300750` 或 `NDSD` 等拼音首字母，最多展示 5 条相关候选，点击右侧“＋”连续添加。
- **默认拼音代号**：旧版系统分配的 A01 等代号一次性迁移，保留其他自定义代号；同名自动加后缀。
- **价格速览**：持仓 / 提醒编辑页顶部显示最高价、当前价、最低价，当前价略大，标明行情时间。
- **清空单项持仓**：确认后归零该项数量和成本，保留自选与提醒。
- **到价及盈亏提醒**：价格涨到 / 跌到、单项浮动盈利 / 亏损（金额或百分比），可与原涨跌幅提醒同时启用。规则每日去重，收起面板仍在交易时段持续监测。
- **上一只 / 下一只快捷键**：按自选顺序循环切换状态栏关注项，不展开面板；支持左右方向键和三组快捷键冲突检测。

## 应用内更新与清理

偏好 → 版本与更新 → 检查更新 → 立即更新。下载匹配芯片的正式版 ZIP，校验 SHA-256、应用标识、版本、签名与架构，在原位置替换并重启。新版启动确认后删除下载包、解压文件、助手及旧应用；失败时保留或恢复旧版本。若回滚本身失败，保留恢复所需备份。

更新准备期间普通退出会暂缓，待更新助手接管后自动重启；请勿强制结束进程。强制退出、断电或目录失去写权限时可能留下恢复文件，不保证完成自动清理。

只在用户点击后安装，不后台擅自升级。请安装到 `/Applications/Tickfin.app` 或 `~/Applications/Tickfin.app`，确保目录可写；缺少兼容资产或校验信息时提供手动下载。新增单实例保护及当前应用位置入口。

**从 v1.2.0 升级需手动替换一次**，之后可使用应用内更新。退出旧版，将新包中的 Tickfin 拖入 Applications 并选择替换，弹出 DMG，删除下载目录中的多余应用副本。不要删除持仓数据目录。

## 数据与兼容性

- 自选、持仓、提醒和快捷键沿用 `~/Library/Application Support/StockBar`，更新不替换该目录。
- 旧版未记录代号来源，手工设为已分配 A01 等编号的代号也可能被迁移；升级前可备份 `state.json`。
- 清空持仓保留提醒；数量或成本为零时暂停盈亏提醒，重新录入后恢复。
- 仅支持沪深北 A 股与沪深场内 ETF；不支持 LOF、场外基金或指数。行情可能延迟，提醒按间隔采样。
