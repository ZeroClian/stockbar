# Tickfin v1.2.2

新增 Bark 手机 / 手表通知，以及状态栏“涨跌幅＋现价”模式。保留小面板、默认隐藏持仓及后台监测。

## 新功能

- **Bark 推送**：偏好 → Bark 推送，配置 HTTPS 服务地址和设备密钥，启用并保存；再到自选项 → 提醒选择“Bark 推送”。支持官方及自建服务。
- **可编辑文案，固定关键信息**：标题和补充说明可自定义，代号、规则类型和行情时间由程序生成，不能修改或删除。默认不发送价格或盈亏；可主动开启“发送阈值和触发数值”。
- **手机与 Apple Watch**：推送到 iPhone 的 Bark，通过 Watch 通知镜像接收。手表显示取决于手机锁屏、手表佩戴 / 解锁、通知权限及专注模式；相同 Apple 账号本身不会转发 Mac 通知。
- **状态栏组合显示**：偏好 → 状态栏 → 涨跌幅＋现价，例如 `+3.00% · 103.00`。股票价格两位小数、ETF 三位；图钉及上一只 / 下一只快捷键同步切换，旧行情标记“旧”。原有图标和涨跌幅模式保留。
- **文档整理**：简化 README，更新当前原生界面图片，详细操作和计算口径移入使用指南。

## 通知与隐私

Bark 默认关闭，设备密钥保存在本机钥匙串，不写入持仓文件或 URL。默认固定信息只发代号、规则和时间；自定义文案仍会一并发送，请勿主动填入不希望传出的信息。只有服务确认成功才记录每日去重；失败至少间隔 60 秒，对仍满足条件的新鲜行情重试。网络结果不确定时可能重复，不保证端到端恰好一次。

面板收起仍监测，Mac 必须运行且未休眠，休市暂停。测试通知使用标明的示例数据，不使用真实持仓或消耗提醒次数。尚未完成真实 iPhone / Apple Watch 接收及钥匙串授权交互验收。

## 安装与升级

| 文件 | 用途 |
| --- | --- |
| `Tickfin-1.2.2-arm64.dmg` | Apple Silicon 安装包，推荐 |
| `Tickfin-1.2.2-arm64.zip` | 手动安装 / 应用内更新 |
| `SHA256SUMS.txt` | 下载完整性校验 |

v1.2.1 用户可在“偏好 → 版本与更新”检查并立即更新。更新成功后清理下载包、助手和旧版；自选、持仓、提醒及快捷键保留。更早版本需退出后手动替换 `/Applications/Tickfin.app`。Bark 密钥不在 `state.json` 备份中，迁移电脑需重新配置；新版本数据不保证可由旧版读取。

部署目标 macOS 13+，仅发布 arm64；最低系统版本未实机验收。包采用 ad-hoc 签名，未 Developer ID 签名 / 公证。首次打开请参考[安装说明](https://github.com/ZeroClian/stockbar/blob/v1.2.2/docs/INSTALL.md)。

[验证范围](https://github.com/ZeroClian/stockbar/blob/v1.2.2/docs/VALIDATION.md)记录自动化、原生预览及未覆盖的实机边界。
